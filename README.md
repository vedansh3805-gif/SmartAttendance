# SmartAttendance

AI-based Smart Attendance System using face recognition.

## Features

- Face-based attendance recognition
- Student registration
- Faculty dashboard
- Attendance records
- Reports
- Automated attendance marking
- Database management
- Web-based interface

## Technologies

- Python
- Flask
- OpenCV
- HTML
- CSS
- JavaScript
- SQLite
